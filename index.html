🚀 IFrame & Custom Event Catcher

A Manifest V3 Chrome Extension to intercept, log, persist, and analyze cross-frame postMessage communications, iframe lifecycles, and custom DOM events in real time.

View Dashboard & Sandbox GitHub Repository

🛰️ PostMessage Interception

Intercepts inbound, outbound, and cross-frame postMessage events across top windows and embedded iframes.

⚡ Custom Event Monitoring

Tracks dispatches of custom CustomEvent objects across all execution frames and main DOM worlds.

💾 IndexedDB Persistence

High-capacity log persistence using IndexedDB with configurable auto-cleanup and retention management.

🧪 Interactive Sandbox

Built-in playground to generate test events, insert dynamic iframes, and inspect live payload structures.
